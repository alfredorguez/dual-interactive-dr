# Security Policy

## Supported versions

Only the latest version on the `main` branch receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
("Security" tab → "Report a vulnerability"), or by email to
a.rodmagdalena@gmail.com.

Include a description of the problem, the steps to reproduce it and the
affected version. We will acknowledge the report as soon as possible and keep
you informed until it is resolved.
